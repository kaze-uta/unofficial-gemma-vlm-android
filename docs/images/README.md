# 記事用の画像置き場

`docs/qiita-article.md` から参照している画像をここに置きます。
下記のファイル名で保存すれば、記事にそのまま反映されます。

| ファイル名 | 内容 | 記事中の場所 |
|---|---|---|
| `demo.gif` | 撮影 → 端末内で画像解析する一連の動きのGIF | 2. 作ったもの（冒頭） |
| `home.png` | 起動後のモード選択画面 | 2. 作ったもの |
| `chat.png` | テキストチャット画面 | 2. 作ったもの（テキストチャット） |
| `image-analysis.png` | カメラ画像解析の結果画面 | 2. 作ったもの（カメラ画像解析） |

## メモ

- スクショは実機 / エミュレータどちらでもOK。縦長スクショはそのまま貼ると大きいので、必要なら幅を調整してください。
- GIF が用意できなければ `demo.gif` の行は静止画に差し替えても大丈夫です（記事側の `![...](images/demo.gif)` のファイル名も合わせて変更してください）。
- **Qiita に投稿するときの注意**: Qiita はローカルの相対パス画像をそのまま表示できません。Qiita の編集画面に画像をドラッグ&ドロップでアップロードすると `![](https://qiita-image-store...)` のようなURL付きMarkdownが生成されるので、記事中の `![...](images/xxx.png)` をそのURLに置き換えて投稿してください。
